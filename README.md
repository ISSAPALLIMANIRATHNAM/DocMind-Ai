# DocMind-Ai
DocMind AI — Chat with Your Documents

DocMind AI is a document question-answering project that lets users upload PDF files and ask questions about their content. Instead of manually searching through pages to find information, users can ask questions in normal language and get answers based on the document.

The project uses Retrieval-Augmented Generation (RAG) to find relevant information from uploaded documents and pass it to a language model to generate useful answers. It also supports general questions when no PDF is uploaded, depending on the selected model and application settings.

The main idea behind this project is to make finding information in documents easier, faster, and more convenient.
